# Arpit Singh — Developer Portfolio

A modern, responsive **React.js** portfolio website built with **Vite**, featuring smooth animations, a dark/light theme, and interactive UI components.

## 📸 Sections

| Section                | Description                                                                         |
| ---------------------- | ----------------------------------------------------------------------------------- |
| **Home**               | Intro with typing name animation, roles, and profile image with orbiting tech icons |
| **Featured Projects**  | Cards for each project with GitHub & Live Demo links                                |
| **Skills & Expertise** | Animated skill progress bars grouped by category                                    |
| **Experience**         | Interactive timeline of education and professional experience                       |
| **Certifications**     | Carousel of professional certifications                                             |
| **Connect With Me**    | Contact form + social links (GitHub, LinkedIn, Email)                               |

## 🛠️ Tech Stack

**Frontend**

- React.js (Vite)
- Vanilla CSS (CSS variables, glassmorphism)
- Google Fonts — Syne & DM Sans

**Features**

- Scroll-reveal animations (`IntersectionObserver`)
- Animated skill bars
- Certifications carousel
- Typing name & role animation
- Orbiting tech icon ring animation
- Fully responsive layout

## ⚙️ Getting Started

### Prerequisites

- Node.js ≥ 18
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/arpitsingh39/<repo-name>.git

# Navigate into the project
cd portfolio-v2

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
